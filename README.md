# Machine Learning Practice 🚀

A hands-on journey into Machine Learning using Python and Scikit-learn. Practising different algorithms, exploring datasets, and learning through real-world examples.

## 📚 Topics Covered

- **Linear Regression** – Regression and price prediction
- **Supervised Learning** – Classification techniques
- **Clustering** – K-Means clustering
- **Ensemble Learning** – Random Forest, AdaBoost, Gradient Boosting and Stacking
- **Hyperparameter Tuning** – GridSearchCV and RandomizedSearchCV
- **Heart Disease** – Data analysis and preprocessing
- **Insurance** – EDA and feature engineering

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
